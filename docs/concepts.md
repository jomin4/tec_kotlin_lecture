# 🪜 개념 인벤토리 (학습 사다리)

지금까지 배운 개념을 한눈에. 강의마다 "뭐가 새 개념이고 뭐가 반복인지" 판단하는 기준표.

## 상태 표시
- ✅ **익숙** — 반복 설명 불필요, 그냥 사용
- 🔁 **복습** — 최근 배움, 나오면 1줄만 상기
- 🆕 **학습중** — 아직 낯섦 → **나올 때마다 제대로 짚고 넘어간다**

> 갱신 규칙: 강의를 끝낼 때마다 이 표를 갱신한다. 🆕가 충분히 익으면 🔁로, 🔁가 익으면 ✅로 승급.

## 지금 집중해서 반복 설명할 것 (🆕)
1. **함수를 값으로 다루는 모든 것** — 람다, 함수 타입, 고차함수, `it`, 트레일링 람다, `::`, 함수 반환. (사용자 요청: 처음이라 매번 짚기)
2. **함수형 심화** — `inline`/`reified`, 변성 `in`/`out`, 위임 `by`, 시퀀스.

> 이 목록의 개념이 강의에 나오면 그냥 쓰지 말고 **"이건 이런 거였지"** 하고 한 번 더 풀어서 설명한다.
